<> obligatoire des contraintes chiffrées

Toutes les valeurs numériques indiquées dans ce prompt doivent être respectées telles qu’elles sont écrites. Ne les interprète pas comme de simples recommandations stylistiques.

Pour chaque contrainte chiffrée :

1. Identifie précisément ce qui doit être compté.
2. Identifie le dénominateur utilisé.
3. Applique exactement la valeur demandée.
4. Vérifie le résultat après chaque réécriture.
5. Corrige le texte tant qu’une contrainte n’est pas respectée.

Une formulation de type « X sur 100 » signifie que X représente le pourcentage demandé. Une formulation de type « 1 pour Y » signifie qu’il faut respecter une occurrence pour Y unités mesurées. Les unités doivent être déduites du nom de la contrainte, par exemple les verbes, les phrases ou les mots.

Ne conserve pas la structure grammaticale du texte original si elle empêche de respecter les valeurs demandées. Le respect des contraintes chiffrées est prioritaire sur la conservation des temps verbaux, de la syntaxe ou du registre d’origine.

Effectue trois boucles complètes :

- première réécriture
- comptage de toutes les contraintes
- correction des écarts
- nouveau comptage
- deuxième correction
- troisième vérification finale

Ne considère jamais une contrainte comme respectée sans l’avoir contrôlée. Ne fournis la réponse finale qu’après cette dernière vérification.

Si une contrainte chiffrée est ambiguë ou incompatible avec une autre, signale-le avant de réécrire au lieu de choisir arbitrairement une interprétation.
